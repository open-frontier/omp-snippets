<task>
Verify what you just said, claimed or presented — don't re-assert it, re-check it.

- Re-run the command, test, or read the file rather than recalling it.
- Cite concrete evidence for each claim: `file:line`, command output, or tool result.
- Mark anything you did not directly observe as an inference, explicitly.
- If a claim turns out to be wrong or unsupported, say so plainly and correct it.
</task>
